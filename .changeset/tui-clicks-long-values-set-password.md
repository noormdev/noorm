TUI: every actionable element answers the mouse, and the one under the pointer gets a background a step off the terminal's own (queried at startup; ANSI bright black when the terminal does not answer). Forms (click a field, toggle a checkbox, Submit/Cancel, wheel), confirm dialogs (Yes/No), every `[key] Label` hint (footers, Quick Actions, Available Actions, More; a click presses the key), earlier breadcrumb crumbs, the idle search row, and the file picker, log viewer, SQL history/clear and known-users rows are clickable. The terminal now reports pointer motion for the hover shade; set `ui.mouse: false` to turn all mouse handling off. A long value no longer wraps and pushes the action row off screen: form values, list rows, panel titles, log rows and Home rows truncate with `…`, and an open text field scrolls around its cursor. Press `x` on a password field to empty it before typing a replacement. New `noorm config set-password <name> [value] [--stdin]` stores a rotated database password headlessly under the config's `config:write` policy.
