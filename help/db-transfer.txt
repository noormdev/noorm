DATA TRANSFER - Copy data between databases, export/import .dt files

USAGE

    noorm db transfer
    noorm -H db transfer --to <config> [options]
    noorm -H db transfer --export <path> [options]
    noorm -H db transfer --import <path> [options]

DESCRIPTION

    Transfers data between databases, or exports/imports using the portable
    .dt file format. Supports same-dialect and cross-dialect transfers.

    Tables are automatically ordered by foreign key dependencies to ensure
    referential integrity. Same-server transfers use efficient direct SQL;
    cross-server transfers use batched reads/writes with automatic type
    conversion between dialects.

    The .dt format supports three file types:
      .dt     Plain text (human-readable JSON5)
      .dtz    Gzip-compressed
      .dtzx   Encrypted (AES-256-GCM) + compressed (requires --passphrase)

    TUI mode provides an interactive wizard with export/import options.
    Headless mode requires one of --to, --export, or --import.

SUBCOMMANDS

    (none)          Interactive transfer wizard

CONFLICT STRATEGIES

    fail            Abort on first primary key conflict (default)
    skip            Skip conflicting rows, continue transfer
    update          Update existing rows with source data
    replace         Delete and re-insert conflicting rows

FLAGS (HEADLESS)

    --to            Destination config name
    --export        Export path: file (single table) or directory (multi-table)
    --import        Import from .dt file path (.dt, .dtz, or .dtzx)
    --compress      Compress export as .dtz (default: plain .dt)
    --passphrase    Encryption passphrase (produces .dtzx, implies compression)
    --tables        Comma-separated list of tables (default: all)
    --on-conflict   Conflict strategy: fail, skip, update, replace
    --batch-size    Rows per batch for cross-server (default: 1000)
    --truncate      Truncate destination tables before transfer/import
    --no-fk         Do not disable foreign key checks
    --no-identity   Do not preserve identity/auto-increment values
    --dry-run       Show transfer plan without executing

    One of --to, --export, or --import is required. They are mutually
    exclusive and cannot be combined.

EXPORT PATH RULES

    The --tables flag is required for export.

    Single table (--tables users):
      --export ./data/users.dt     → writes to ./data/users.dt
      --export ./data/users        → writes to ./data/users.dt (appends .dt)
      --export ./data/users --compress → writes to ./data/users.dtz

    Multiple tables (--tables users,posts,comments):
      --export ./backup/           → creates ./backup/users.dt, ./backup/posts.dt, etc.
      --export ./backup/ --compress → creates ./backup/users.dtz, ./backup/posts.dtz, etc.
      --export ./backup/ --passphrase "key" → creates ./backup/users.dtzx, etc.

EXAMPLES

    # Interactive mode
    noorm db transfer

    # Transfer all tables from active config to backup
    noorm -H db transfer --to backup

    # Transfer specific tables
    noorm -H db transfer --to backup --tables users,posts,comments

    # Transfer with upsert behavior
    noorm -H db transfer --to backup --on-conflict update

    # Preview transfer plan
    noorm -H db transfer --to backup --dry-run

    # Clear destination tables before transfer
    noorm -H db transfer --to backup --truncate

    # JSON output for scripting
    noorm -H --json db transfer --to backup

    # Export single table (plain .dt)
    noorm -H db transfer --export ./data/users.dt --tables users

    # Export single table compressed
    noorm -H db transfer --export ./data/users --tables users --compress

    # Export multiple tables to directory (plain .dt per table)
    noorm -H db transfer --export ./data/backup/ --tables users,posts,comments

    # Export multiple tables compressed
    noorm -H db transfer --export ./data/backup/ --tables users,posts --compress

    # Export with encryption (implies compression)
    noorm -H db transfer --export ./data/backup/ --tables users,posts --passphrase "my-secret"

    # Import from a .dt file
    noorm -H db transfer --import ./data/users.dt

    # Import with upsert, filtering tables
    noorm -H db transfer --import ./data/backup.dtz --tables users --on-conflict update

    # Import encrypted file
    noorm -H db transfer --import ./data/backup.dtzx --passphrase "my-secret"

    # Validate schema compatibility only (dry run import)
    noorm -H db transfer --import ./data/backup.dt --dry-run
